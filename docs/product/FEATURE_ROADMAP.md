# Feature roadmap

All items below are **not built** unless marked; flags exist but are off.

## Now (this MVP)
Share-first generator described in MVP_SCOPE.md.

## Next smallest, highest value
1. Test with 5+ real Clarity files from real users on their own devices; fix the parser.
2. Test exports on iPhone Safari and Android Chrome, and in Instagram/Threads/etc.
3. Clinician/educator review of preset copy.

## Later (flag-gated, only if validation passes)
| Phase | Feature | Flag |
| --- | --- | --- |
| 2 | Event icons on the trace (meals, activity) with a slide-up logging sheet | `eventLogging` |
| 2 | Glucose timeline view | `glucoseTimeline` |
| 3 | Accounts and optional cloud save | `accounts` |
| 3 | Dexcom API / Apple Health import | `dexcomApi`, `appleHealth` |
| 4 | Opt-in sharing to a feed; clubs | `communityFeed`, `clubs` |
| 4 | Recipe book | none yet |
| 5 | Year-in-review "Wrapped" (no rankings) | `wrapped` |

Each phase needs its own privacy review. Nothing ranks people by glucose outcomes.
